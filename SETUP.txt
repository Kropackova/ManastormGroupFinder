MANASTORM GROUP FINDER - what goes where


1. TO PLAY WITH IT RIGHT NOW

Use release/ManastormGroupFinder.zip. Extract it and move the folder it
contains into:

  <WoW folder>\Interface\AddOns\ManastormGroupFinder\

The .toc and the four .lua files must sit directly in that folder. If you end
up with AddOns\ManastormGroupFinder\ManastormGroupFinder\... move the inner
folder up one level. Restart the client, enable the addon at character select,
type /msgf.


2. TO PUBLISH IT ON GITHUB

Everything else in this archive is the repository. Do not nest it, these files
belong at the repository root:

  README.md                     the front page, links to docs/*.png
  LICENSE                       MIT
  CHANGELOG.md                  version history
  .gitignore                    ignores zips, editor junk, WTF
  ManastormGroupFinder.toc      addon files, at the root on purpose
  Parser.lua
  Core.lua
  Alerts.lua
  UI.lua
  README.txt                    the in-game manual, kept for players
  docs/                         screenshots the README points at
  release/                      built zip, ignored by git

Steps:

  a) Save your three screenshots into docs/ with these exact names:
       docs/window-lfg.png   the wide LFG table
       docs/window-lfm.png   the LFM table with Aura req / Looms req
       docs/filters.png      the open filter panel
     Then delete docs/PUT-SCREENSHOTS-HERE.txt.

  b) Create an empty public repository named ManastormGroupFinder on GitHub.
     Do not let GitHub add a README or a licence, you already have both.

  c) From this folder:

       git init
       git add .
       git commit -m "Manastorm Group Finder 2.3"
       git branch -M main
       git remote add origin https://github.com/<you>/ManastormGroupFinder.git
       git push -u origin main

  d) Cut a release: on GitHub go to Releases, Draft a new release, tag v2.3,
     title "Manastorm Group Finder 2.3", paste the 2.3 section of
     CHANGELOG.md as the notes, and attach release/ManastormGroupFinder.zip
     as a binary. That attached zip extracts to a correctly named folder, so
     players never have to rename anything. Link people to the release, not
     to the green Code button.

  e) For every future version: bump "## Version:" in the .toc, add a section
     to CHANGELOG.md, commit, tag, and attach a fresh zip built with

       zip -r ManastormGroupFinder.zip ManastormGroupFinder

     from a directory where the addon files sit inside a folder of that name.


3. WHERE TO POST IT

  - Project Ascension Discord, addon channel
  - Project Ascension forums
  - r/wowservers or the Ascension subreddit

Lead with the screenshots and mention that the addon only reads chat and only
acts when you click, which heads off the usual automation suspicion.
